這一版以安全性為主，**已經開過 TUN 的 macOS 使用者請務必更新**。

## 安全性

- **macOS TUN 改用系統背景服務**：舊版用 setuid 授權 mihomo 核心，電腦上任何程式都能拿它免密碼取得最高權限。新版改由 LaunchDaemon 以 root 執行核心，核心與資料夾都屬於 root，Sky 只透過 API 推送設定。更新後第一次啟動會提示「升級授權」，需要輸入一次管理員密碼，舊的 setuid 檔案會被刪除。
- **開放區域網路時一定要帳號密碼**：「允許區域網路連線」開啟後，其他裝置要用 Sky 產生的帳號密碼才能連，本機程式免密碼；帳號密碼在「設定 → 網路」可以複製或重新產生。
- **mihomo 核心更新會驗證 SHA-256**：與 GitHub 官方雜湊值不符就拒絕安裝。安裝包內附的核心也改成只從 mihomo 官方 Release 下載並驗證（v1.19.34）。

## 穩定性

- 改規則或訂閱時不再凍結畫面（設定檢查移到背景）
- Sky 當掉或被強制結束時，會自動關掉系統代理，避免整台電腦斷網；「設定」也新增「重設系統代理」
- 主視窗與選單列都沒開時，背景更新放慢為每 5 秒一次，比較省電
- Windows：使用者名稱含 `'` 時核心更新失敗的問題

## 開發

- 新增單元測試（訂閱解析、設定檔產生、mihomo 實際驗證），Mac 與 Windows 共用測試檔
- 新增 GitHub Actions：自動測試、建置，並在 Windows 主機上實際啟動 App 確認核心能運作
